# Mapa de assets locales

Coloca aqui el material descargado usando estos nombres para que la web lo coja automaticamente:

`assets/media/video/hero.mp4`
Video principal de la home.

`assets/media/hero/hero-poster.webp`
Imagen de respaldo del hero mientras carga el video.

`assets/media/productos/zeus.webp`
Imagen principal de Zeus.

`assets/media/productos/heracles-xl.webp`
Imagen principal de Heracles XL.

`assets/media/productos/andromeda.webp`
Imagen principal de Andromeda.

`assets/media/banners/feature-mesa.webp`
Imagen grande del bloque "Puzzles, juegos y cena en la misma mesa?".

`assets/media/banners/complementos.webp`
Banner del bloque de complementos.

`assets/media/banners/trabajos-realizados.webp`
Banner del bloque de trabajos realizados.

`assets/media/banners/resenas.webp`
Banner del bloque de resenas.

Notas:
- Puedes usar `.webp`, `.jpg` o `.png`, pero si cambias la extension tendras que actualizar la referencia en `index.html` o en `data/productos.json`.
- Mientras falte algun archivo, la web mostrara un placeholder visual para que no se rompa el layout.
