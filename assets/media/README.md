# Inventario de assets

Este archivo sirve como checklist para ir subiendo imagenes y video sin tocar codigo.

## Regla general

- Si subes el archivo con el nombre exacto indicado abajo, la web lo detecta sola.
- Si aun no existe, la tarjeta o bloque mostrara un placeholder y el layout no se rompe.
- Formato recomendado: `.webp`
- Si usas otra extension, hay que actualizar la referencia en `index.html` o en los `.json`.
